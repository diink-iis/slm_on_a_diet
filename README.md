# slm_on_a_diet
**Исследование методов сжатия и ускорения малых языковых моделей (SLM)**

**Описание:** Большие языковые модели (типа GPT-4) требуют огромных ресурсов. Задача — исследовать методы адаптации малых моделей (1B-3B параметров, например Qwen или Llama) для решения конкретной задачи (например, генерации кода или решения математических задач) на слабых GPU. Сравнение квантования, LoRA-адаптации и прунинга.

**Что исследовать:** Какой баланс между качеством и скоростью работы можно достичь на потребительском железе.
